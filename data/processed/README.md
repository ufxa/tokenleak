# Processed Data

Processed cache bitmaps and profiling statistics derived from raw timing measurements.

Contents generated by the simulation harness:
- `cache_fingerprints/` — per-token cache bitmap vectors (L=256 cache sets)
- `timing_profiles/` — per-token (mu_tau, sigma_tau) pairs

Regenerate with:

```bash
python3 -m src.evaluation.evaluate
```

Final results are saved to `../results/accuracy_vs_noise.csv`.
